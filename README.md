# Install Wired

Wired is our family's app for watching, reading and listening. Install it once; after that it updates itself (a banner says **"Wired x.y is ready"**, press **Update**).

You need the family sign-in to use it. Ask for it if you don't have it.

## Windows PC

1. Download **[Wired for Windows](https://github.com/globaltexan1/wired-download/releases/latest/download/Wired-windows.zip)**.
2. Right-click the file → **Extract All…** → choose a folder you'll keep (for example *Documents\Wired*).
3. Open the folder and double-click **wired.exe**. Right-click it → *Send to* → *Desktop (create shortcut)* to keep it handy.
4. If Windows says *"Windows protected your PC"*: click **More info → Run anyway** (it's only because the app isn't from a store).

## Android phone or tablet

1. On the phone, open **[Wired for Android](https://github.com/globaltexan1/wired-download/releases/latest/download/Wired-phone.apk)**.
2. Open the downloaded file. If asked, allow your browser to **install unknown apps**, then press **Install**.

## Fire TV, Google TV, Android TV

1. On the TV, install the free app **Downloader** (by AFTVnews) from the TV's app store.
   - Fire TV only: *Settings → My Fire TV → Developer options → Install unknown apps → Downloader → On*.
2. Open Downloader, select the address box and type:
   `globaltexan1.github.io/wired-download`
3. Press **Wired for TV**, then **Install**.
4. Open Wired. It shows a code: on your phone, open Wired → *Settings → Account → Sign in a TV* and enter it.

## Signing in

- Phone and PC: Settings → Sign in with the family email and password, then pick your profile (or create one).
- TV: approve the code from a phone that's signed in.

Your profile keeps your own *Continue watching*, likes and library; everything else (sources, settings) is already set up.
